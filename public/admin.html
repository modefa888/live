📋 获取参数指南

          
1. 打开一个抖音直播间（如 live.douyin.com 任意主播）

          
2. 按 F12 → Console 面板

          
3. 点击「一键获取参数」→ 复制代码 → 切回直播间 → Ctrl+V

          
4. 如被拦截 → 输入 allow pasting → 回车 → 再 Ctrl+V → 回车

          
5. Console 输出 JSON → 复制到下方「📥 粘贴参数」→ 填入参数

📋 获取直播搜索参数指南

          
1. 打开 www.douyin.com → 搜索任意关键词 → 点「直播」筛选

          
2. 按 F12 → Network 面板 → 过滤 live/search

          
3. 点击那个请求 → 在 Payload 里找到 a_bogus 和 msToken

          
4. 复制到下方输入框（Cookie 可选，从请求 Headers 复制）

          
5. 注意：福袋的 a_bogus 不能用于直播搜索，必须从搜索请求抓取

        

        
        
        
        
        
        
        

          
          
        

        

          
🎬 推荐直播 URL（完整 URL，从浏览器复制）

          

            
1. 打开 live.douyin.com（直播首页）

            
2. 按 F12 → Network 面板 → 过滤 feed

            
3. 找到 webcast/feed 请求 → 右键 → 复制为 cURL

            
4. 从 cURL 中提取完整 URL（含 a_bogus 和 msToken）粘贴到下方

            
⚠️ 该 URL 有时效性，a_bogus 失效后需重新获取

          

          
        

        

          
🔍 直播搜索 URL（完整 URL，从浏览器复制）

          

            
1. 打开 www.douyin.com → 搜索任意关键词 → 点「直播」筛选

            
2. 按 F12 → Network 面板 → 过滤 live/search

            
3. 找到 live/search 请求 → 右键 → 复制为 cURL

            
4. 从 cURL 中提取完整 URL（含 a_bogus 和 msToken）粘贴到下方

            
⚠️ 填写后直播搜索直接使用该 URL（自动替换关键词），无需再单独填 msToken/a_bogus
